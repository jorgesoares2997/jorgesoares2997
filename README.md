## Projetos em destaque

Aplicação Web3 (Stellar/Soroban) para criação de pactos sociais entre grupos de amigos, com staking em USDC e resolução por votação coletiva.
**Tecnologias:** Rust, Soroban, React, TypeScript
**Repositório:** [jorgesoares2997/pact-chain](https://github.com/jorgesoares2997/pact-chain)

### 🔗 Predict.IO

**Tecnologias:** Rust, Soroban, React, TypeScript
**Repositório:** [jorgesoares2997/predict_io](https://github.com/jorgesoares2997/predict_io)
**Demonstração:** [predi-ct-io.vercel.app](https://predi-ct-io.vercel.app/)
